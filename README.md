# 🏔️ UnderPeak

**UnderPeak – Explore the World Beneath Your Feet**

UnderPeak is an Android application designed to help users discover and explore caves. The app combines cave information, interactive exploration features, navigation support, and personal journey documentation to create an engaging caving experience.

## 📱 Features

- 🗺️ **Cave Exploration** – Discover caves and access information about different locations.
- 🧭 **Cave Maps** – View cave maps to support navigation and exploration.
- 📍 **Checkpoints** – Use checkpoints to follow and document cave journeys.
- 📸 **Camera Integration** – Capture photos during cave exploration.
- 🖼️ **Photo Timeline** – View and organize images from exploration sessions.
- ❤️ **Favorites** – Save favorite caves for easier access.
- ⏱️ **Timer** – Track time during exploration activities.
- 📖 **Beginner Guide** – Access information and guidance for beginners.
- 🎒 **Exploration Planning** – Prepare for cave exploration activities.

## 🚀 Installation

1. Clone this repository or download the project as a ZIP file.
2. Open **Android Studio**.
3. Select **Open** and navigate to the `UnderPeak` project directory containing `settings.gradle.kts`.
4. Wait for Gradle synchronization to complete.
5. Connect an Android device or start an emulator.
6. Click **Run ▶** to build and launch the application.

### Requirements

- Android Studio
- Android SDK 36 for compilation
- Android 7.0 (API 24) or newer
- Java 11 compatibility
- Gradle 8.13 (configured in the project)

## 🎯 Project Goals

The main goals of UnderPeak are to:

- Make cave exploration more accessible and engaging.
- Provide useful information about caves.
- Help users prepare for and document their exploration journeys.
- Combine navigation, photography, and exploration tools in one application.
- Create a user-friendly Android experience.

## ⚠️ Safety Notice

UnderPeak is intended as an informational and exploration-support application. It is not a replacement for professional cave navigation equipment, appropriate safety training, or experienced guides.

Always follow local regulations and established cave safety procedures.
